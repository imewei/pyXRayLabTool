# Package JAX-first Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the NumPy/`ops` core calculators, the per-element interpolators and the process-pool batch path with one `jax.numpy` implementation: resident stacked scattering tables, one device program per public call (single upload, single fetch), `vmap` over materials for batches, bounded recompilation, host code only at the exempt edges.

**Architecture:** `ScatteringTables` (padded `[Z, N]` arrays x/f1/f2 plus precomputed PCHIP slopes, shipped as `scattering_tables.npz`, uploaded once, passed as a program argument) feeds pure functions in `calculators/optics.py` (`interpolate_f`, `derive`, `optical_properties`); `core.py` validates and encodes on the host, makes one program call over bucketed `(F, K, M)` shapes and builds `XRayResult`. The generic runtime helpers of `kk` (`upload`/`fetch`/`ensure_x64`/persistent cache/`bucket`) move to `backend/` and are shared. Public names are kept except the removals in spec §8.

**Tech Stack:** Python ≥3.12, JAX (x64) on CPU/GPU, NumPy only at exempt boundaries (spec §9), pytest, mypy `--strict`, ruff, uv.

**Spec:** `docs/superpowers/specs/2026-10-26-package-jax-first-design.md` (read it first; this plan uses its section numbers as §n). Precedent: `docs/superpowers/plans/2026-10-25-kk-jax-first.md`.

## Global Constraints

- Owner's directive (2026-10-26): the **entire package is JAX-first, mandatory**; no further questions. kk is already JAX-only. No NumPy twin of any algorithm, no `ops` dispatch, no SciPy PCHIP at runtime, no `pure_callback`/`io_callback`, no float32.
- Python ≥ 3.12; `mypy xraylabtool/ --strict`, `ruff check` and `ruff format` clean (split helpers instead of `noqa` for PLR0912/PLR0915); NumPy-style docstrings with `References`; explicit imports.
- float64 always (ADR-003). `runtime.ensure_x64()` runs at every concrete public compute entry and worker entry; programs also run inside `jax.enable_x64(True)` scopes (as `JaxPchipInterpolator` does) so another library's x64 setting cannot degrade them.
- Transfers per ADR-004 and spec §1: the only crossings are `runtime.upload`, `runtime.fetch`, `runtime.fetch_status`; the device-only region runs under `jax.transfer_guard("disallow_explicit")` in tests; budgets are asserted from the counters (≤ 1 upload call, ≤ 1 fetch call per public call).
- Capacities and buckets are conservative host-side bounds (spec §3); padding invariance is tested bit-exact.
- `filterwarnings = error`; divide/invalid warnings are ignored by config, so numerical tests assert `np.isfinite(...).all()` explicitly. A JAX `RuntimeWarning` about fork is a test failure by design: no pool may fork after JAX starts.
- `import xraylabtool` must not import `jax` or `xraylabtool.kk`; neither may `--help`, `--version`, `completion`, `formula`, `atomic`, `list`. GUI tests run serially (add new GUI test files to the Makefile `GUI_TESTS` list **and** `.github/workflows/ci.yml` `IGNORE_GUI`). CI has no GPU: every test must pass on JAX-CPU **and** on a CUDA host (run both before committing a stage).
- **Goldens** are frozen from the NumPy path in Task 0 and never loosened (`rtol=1e-12`; `atol` only where the golden is exactly 0). Where XLA fusion differs by one ulp use `tests/fixtures/kk_rounding.py::assert_kk_close`, with the rationale in the test docstring.
- Behaviour parity (spec §6): exception types and messages, skip-and-log batch semantics, negative f1 near edges kept, output order equals input order.
- Test names must not contain `performance`, `benchmark` or `timing` unless intended: `tests/conftest.py` auto-marks such names `performance` (skipped without `--run-performance`). `scripts/core_bench.py` and `scripts/core_gpu_check.py` are standalone scripts, not collected.
- **Do not start implementing until Wei asks.** At execution start: work on branch `feat/jax-first-core` (cut from `feat/jax-native-pchip`, which carries the in-tree PCHIP and its hardening); commit this spec and plan first, `graphify update .` as a separate commit; push only as part of a PR Wei asks for; never force-push or merge.
- Environment: commits need gpg, so run `git commit`, `gh` and GPU checks with `dangerouslyDisableSandbox`; `uv sync` **without** `--extra gpu_cuda13` uninstalls the CUDA plugin, so always `uv sync --extra gpu_cuda13` on this machine. CPU checks: `JAX_PLATFORMS=cpu`.
